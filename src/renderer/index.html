Touche

—

Une même touche peut avoir 3 actions différentes : appui simple, double appui (2 appuis rapides) et appui long (maintenir ~½ s). Un point vert = geste déjà configuré.

⚠ Détection double/long indisponible sur ce système — seul l'appui simple fonctionnera.

Paramètres

OBS Studio

Dans OBS : Outils → Paramètres du serveur WebSocket → Activer. (OBS 28 ou plus récent)

—

Overlay

Mini-deck affiché par-dessus toutes les fenêtres. Déplacez-le en le faisant glisser, puis verrouillez-le : les clics passeront au travers.
